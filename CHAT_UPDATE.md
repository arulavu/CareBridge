# Continued chat update

Patients can ask follow-up questions during intake and after the report. Four visible quick-action buttons prompt common follow-ups or start a new concern. Follow-up responses are constrained educational rules, not a connected LLM. Red flags and possible fractures take precedence over general guidance. Existing reports refresh when new information arrives.

For a real generative AI chat, a secure backend and a medically reviewed, independently evaluated safety architecture are still needed. Do not send real patient information to this demonstration.
